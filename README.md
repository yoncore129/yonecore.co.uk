# Yonatan Yigzaw — Landing Page

A personal landing page for Yonatan Yigzaw, personal trainer with 18+ years of experience, showcasing services for individuals, companies, and schools.

## View locally

Just open `index.html` directly in your browser, or run a local server:

```bash
python3 serve.py
```

Then visit http://localhost:8000

## Deploy with GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to your repo's **Settings** → **Pages**.
3. Under "Build and deployment", set the source to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. GitHub will publish the site at `https://<your-username>.github.io/<repo-name>/`.

Because the file is named `index.html`, it will load automatically as the homepage.
